## 💜 Sobre o projeto

O **RedeSentinela** é uma plataforma que utiliza dados para identificar regiões com maior incidência de violência contra a mulher e menor acesso a serviços de apoio.

Nosso objetivo é contribuir para o fortalecimento da rede de proteção, auxiliando na identificação de áreas mais vulneráveis e promovendo maior acesso à informação.

---

## 🎯 Objetivos

- 📍 Identificar regiões com maior vulnerabilidade.
- 📊 Apoiar análises baseadas em dados.
- 🤝 Fortalecer a rede de apoio à mulher.
- 🛡️ Facilitar o acesso aos serviços de acolhimento.
